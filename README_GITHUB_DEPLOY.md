# GitHub Deployment Instructions for service.html

## How to add this file to your GitHub repository:

### Method 1: Uploading via Web Browser (Easiest)
1. Open your GitHub repository in the browser: `https://github.com/mdzahidul-i-slam/portfolio`
2. Make sure you are on the `main` or `master` branch.
3. Click on the **Add file** button (top right of file list) and select **Upload files**.
4. Drag and drop the `service.html` file into the box.
5. In the "Commit changes" section at the bottom, type a message like: `Add service page HTML and CSS`.
6. Click **Commit changes**.

---

### Method 2: Uploading via Terminal / Git Commands
If you use Git on your local computer, run these commands in your project directory:

```bash
# 1. Place the service.html file inside your project folder
# 2. Add the file to git tracking
git add service.html

# 3. Commit the change
git commit -m "Add service page to portfolio"

# 4. Push to GitHub
git push origin main
```

---

### Verifying the Live Link:
Once uploaded, your new service page will be live at:
`https://mdzahidul-i-slam.github.io/portfolio/service.html`
